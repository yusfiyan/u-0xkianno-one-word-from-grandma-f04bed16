# One Word From Grandma

The single word grandma would text about AI: **Contraption**.

Not "robot" (too obvious), not "magic" (fits any subject), not "scary" (no warmth). A grandma who does not understand a machine calls it a contraption — warm, a little baffled, funny in one word, and unmistakably about a machine.

Run: `node main.ts` (writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt`)
